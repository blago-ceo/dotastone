Сюда можно положить картинки для карт (PNG или JPG, лучше квадратные).
Имя файла = id карты из CardData.cs, например:

  pudge.png, sniper.png, roshan.png, laguna.png, tango.png ...

Портреты героев: hero_axe.png, hero_lina.png, hero_omni.png, hero_furion.png

Если картинки нет, рисуется цветная заглушка с первой буквой имени.
