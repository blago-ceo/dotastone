# DotaStone

Карточная дуэль героев Dota 2 по правилам Hearthstone. Школьный проект.

**Играть:** https://blago-ceo.github.io/dotastone/

## Как играть

- Выбери героя: Шадоу Финд, Инвокер, Пудж или Тинкер.
- **Против бота:** лёгкий или обычный бот.
- **С другом онлайн:** включи «С другом онлайн», выбери героя и нажми «Создать игру». Скажи другу код из 4 символов. Друг открывает ту же ссылку, выбирает героя и входит по коду. Аккаунты не нужны.
- Каждый ход даёт +1 ману (максимум 10). Играй карты с зелёным свечением, атакуй существами, сними вражескому герою 30 здоровья.
- Кнопка «?» на столе показывает правила.

### Герои

| Герой | Сила героя | Мана |
|---|---|---|
| Шадоу Финд | Реквием душ: 2 урона всем вражеским существам | 2 |
| Инвокер | Инвок: взять карту | 2 |
| Пудж | Хук: притянуть вражеское существо на свою сторону | 8 |
| Тинкер | Марш машин: призвать Робота 1/1 | 2 |

## Устройство проекта

| Путь | Что там |
|---|---|
| `index.html` | Готовая страница игры для GitHub Pages (собирается скриптом, руками не править) |
| `web/dotastone.html` | Исходник игры: правила, бот, интерфейс, анимации, 3D-мид, онлайн |
| `web/art/` | Картинки карт и героев в webp; имя файла = id карты (`pudge.webp`, `hero_sf.webp`, `power_sf.webp`) |
| `tools/build_site.py` | Собирает `index.html` из `web/dotastone.html` |
| `tools/embed_art.py` | Зашивает картинки из `web/art/` прямо в страницу |
| `tools/art_tool.py` | Переименовывает и сжимает картинки из папки с русскими названиями |
| `Assets/DotaStone/` | Версия для Unity на C# (отстаёт от веб-версии: нет онлайна, Хука и анимаций) |

### Как поменять игру

1. Правь `web/dotastone.html`. Карты задаются в начале скрипта функциями `minion(...)` и `spell(...)`, герои в массиве `HEROES`.
2. Если менялись картинки: `python tools/embed_art.py web/dotastone.html web/art`
3. Собери страницу: `python tools/build_site.py`
4. Закоммить и запушь: GitHub Pages обновится сам через минуту-две.

### Как работает онлайн

Связь идёт через открытые MQTT-серверы (`broker.emqx.io`, запасной `broker.hivemq.com`) по WebSocket. Хозяин игры держит в «лобби» закреплённое сообщение, друг находит его по коду. Оба браузера строят одну и ту же партию по общему зерну (одинаковые колоды и первый ход) и пересылают друг другу только ходы. Первая буква кода говорит, через какой сервер идёт игра.

Это бесплатные тестовые серверы без гарантий: если онлайн не подключается, попробуй ещё раз или чуть позже.

## Версия для Unity

1. Создай 2D-проект в Unity 2021.3+, 2022.3 или Unity 6.
2. Скопируй `Assets/DotaStone` в папку `Assets` проекта.
3. Открой любую сцену и нажми **Play**: интерфейс собирается из кода.
